# Roadmap

1. **Phone (now):** wake word, voice check, offline commands and chat, tile, notification, kill switch.
2. **Laptop:** a small app with the same wake word, voice check and model, plus v1's work tools (run a Stata do-file, compile LaTeX, git commit). The phone could hand those commands to the laptop when it's on.
3. **iPad:** Apple doesn't allow background wake words or replacing Siri. Plan: a Siri Shortcut ("Hey Siri, Topshe...") that sends the request to the phone or laptop.
4. **Later ideas from v1:**
   - Learn from corrections: when Topshe gets something wrong, you say the right thing, and it remembers for next time.
   - A cloned voice.
   - A calendar tool.
